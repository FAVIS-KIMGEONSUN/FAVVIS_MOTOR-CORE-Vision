## 분석 기준과 읽는 법

분석 대상은 **2026-10-27에 읽은 `E:\모터코어 #65\알고리즘`의 JSON 32개, 처리 노드 1,146개**입니다. 외부 JSON은 수정하지 않았습니다. 각 문서의 상세표에는 원본 해시와 JSON에 기록된 시각을 남겼습니다.

| 구분 | 근거와 한계 |
|---|---|
| 확인한 사실 | `ParamList`의 나열 순서, 각 노드의 `Index`, `Name`, 이미지 참조, `ResultName`, `SaveUse`, 수치 설정. 32개 파일 모두 `Index`와 나열 순서가 일치 |
| 옵션 해석 | 저장소 `ref\processing\DSProcessingDLL_4.8.1.dll`의 모델을 로컬에서 생성해 UI의 `Combo_items`, 파라미터 이름을 조회. 영상처리 함수는 실행하지 않음 |
| 추정 | 도구 이름, 결과명, 참조값을 바탕으로 해석한 결함 검출 목적. 흐름도는 이 목적별 요약이며 모든 단계를 직렬 영상 의존성으로 표현한 것이 아님 |
| 미확인 | 네이티브 구현의 정확한 수식, ROI·출력 이미지 개수와 반환 순서, 물리 단위, 결함 검출 성능. 실제 이미지로 검사를 실행하거나 튜닝한 결과가 아님 |

흐름도의 분기는 **특징 처리 경로**를 뜻하며 병렬 실행을 의미하지 않습니다. 순서는 펼친 **전체 노드 표**가 기준입니다. 모든 도구명은 아래 설명으로 연결됩니다.

상세표의 `I1/I2`는 `Int_slider/Int_slider2`, `P1/P2/P3`는 `Param_slider1/2/3`의 원문 값입니다. 도구마다 의미가 다르며 아래 UI 이름을 참고해야 합니다. `ScaleMin/Max`, 면적·폭·길이 조건 등은 상세표에서 생략했습니다. 따라서 상세표만으로 JSON을 재구성하거나 모든 판정 기준을 확인할 수는 없습니다.

이미지 참조 열은 `Combo_ImageIndex`부터 `Combo_ImageIndex4`까지 **네 값 모두를 원문 그대로** 표시합니다. UI에서 사용하지 않는 입력·옵션에도 기본값이 남아 있으므로 `0`을 모두 실제 연결로 해석하면 안 됩니다. `옵션 없음`은 DLL 모델에 해당 옵션 목록이 없다는 뜻입니다. `미정의`는 목록은 있지만 해당 번호의 이름을 찾지 못했다는 뜻이며 JSON 오류라고 단정하지 않습니다.

**이미지 슬롯과 노드 번호는 다릅니다.** 초기 입력 범위는 `InputNameList`로 확인하지만, 이후 참조는 다중 출력·Crop 등이 포함된 누적 이미지 공간일 수 있습니다. 예를 들어 측면 `Global 스크래치`는 입력 17개인데 `Arithmetic_1`이 25·26을 참조합니다. 앱 편집기의 `입력 수 + Index` 단일 출력 해석을 모든 JSON에 그대로 적용해 생산 노드를 확정하지 않았습니다.

`SaveUse=true`는 JSON에서 결과 저장/노출로 표시한 노드입니다. 이것만으로 파일 저장, Local 입력 위치, 최종 NG 판정을 확정할 수 없습니다. `ResultName`이 `사용X`인 노드도 `ParamList`에 남아 있으면 문서에서 제외하지 않습니다.

## 앱 실행과 JSON 의도는 구분

`MotorCoreVision\Inspection\InspectionManager.cs`에서 확인한 실행 순서는 Mask → (설정된 경우 Hole) → 전체 Global → 전체 Local입니다. Global과 Local은 파일명이 아니라 **설정 목록의 같은 인덱스**로 연결됩니다.

현재 `RunHoleCore()`는 원본 이미지를 입력하고, `GetFinalMaskResult()`는 Hole 결과가 아닌 Mask 결과를 반환합니다. 반면 측면 `Make Hole.json`의 마지막 입력은 `Mask`이고, 일반 Global은 Hole의 저장 결과명과 대응되는 12개 이미지를 기대합니다. 따라서 문서의 **JSON이 의도한 전처리 연결이 현재 앱에서 그대로 성립한다고 보장할 수 없습니다.** 이 문서 작업에서 앱 코드는 변경하지 않았습니다.

현재 앱의 최종 판정은 Local 반환 이미지의 `reult.ROI.Count`를 합산해 0이면 OK, 있으면 NG입니다. 흐름도의 `ImageAnalysis`는 결과 분석 노드이며, 그 자체를 OK/NG 결정 분기로 표시하지 않았습니다.

## 입력 채널 용어

| 표기 | 이 문서에서의 의미 |
|---|---|
| REF / 반사율 | 반사율·명암 계열 입력. 실제 물리적 반사율 보정 여부는 미확인 |
| RGH / RGV / RG2 | 거칠기 H/V/양방향 계열. JSON별 `거칠기(양방향)` 또는 `3RG2` 등의 이름을 유지 |
| INH / INV / IN2 | 기울기 H/V/양방향 계열. 내경의 2DTheta/Phi 변환 입력과 최종 출력명을 구분 |
| R / G / B | 적색·녹색·청색 채널 |
| PolarTheta | 원문 채널 이름의 일부. 반사율·거칠기·기울기 각각에 있으므로 서로 같은 영상이 아님 |
| Mask | 검사·제외 영역을 나타내는 영상. 흰색이 포함 영역인지 제외 영역인지는 도구의 Normal/Reverse 설정에 따라 해석 |
| Blob / ROI | 연결된 후보 영역 / 관심 영역. ROI의 존재와 원본 영상의 밝기 자체를 혼동하지 않음 |

## 밝기·산술·채널 처리

<a id="arithmetic"></a>
### Arithmetic

두 영상의 픽셀별 연산입니다. UI의 Mode는 0 Add, 1 Sub, 2 Multi, 3 Divide, 4 And, 5 Or, 6 XOr, 7 Min, 8 Max, 9 Avg, 10 Diff, 11 Attach, 12 SubOrMin, 13 Std입니다. **이름이 `STD`여도 실제 모드가 Avg인 JSON이 있으므로 설정을 우선**합니다.

`P1=Multi Value`, `P2=Add Value`이며 두 번째 옵션은 보정 적용 순서입니다. 비율 영상은 채널 간 상대 변화를 강조하고, Sub는 배경·제외 영역 제거, And는 마스크 제한, Max는 여러 후보 중 강한 응답 취합에 쓰입니다. 나눗셈 0 처리·포화 연산 등은 구현을 확인하지 않았습니다.

<a id="arithmetic2"></a>
### Arithmetic2

UI 옵션은 Arithmetic과 동일합니다. 측면 녹의 색상 특징 경로에서 사용됩니다. 두 클래스의 내부 차이를 확인하지 못했으므로 같은 구현이라고 단정하지 않습니다.

<a id="allarithmetic"></a>
### AllArithmetic

여러 영상의 취합 연산입니다. 주 옵션은 0 Min, 1 Max, 2 Avg, 3 Std, 4 Mask, 부 옵션은 Manual/InputAll/ResultAll/All입니다. 첫 세 참조만 읽으면 네 번째 입력을 놓칠 수 있습니다. Max 취합은 산술 덧셈·논리 OR와 구분해야 합니다.

<a id="singlearithmetic"></a>
### SingleArithmetic

한 영상의 배율·오프셋·거듭제곱 보정입니다. `P1=Multi Value`, `P2=Add Value`, `P3=Oper Value`; 옵션은 보정 순서와 none/pow입니다. 측면 갭의 양·음 응답 강도 조정 등에 쓰입니다.

<a id="reverse"></a>
### Reverse

밝기 반전 또는 역수형 변환입니다. Mode는 Sub/Devide(원문 표기), `P1=N`, `P2=Base`입니다. 마스크 보수 집합이나 어두운 특징을 밝은 특징으로 바꿀 때 사용합니다. 모든 설정을 무조건 `255-I`로 해석하지 않습니다.

<a id="log"></a>
### Log

로그형 명암 변환은 큰 밝기 범위를 압축하고 어두운 영역의 상대 차이를 드러내는 기법입니다. 측면 Mask에서 `REF_Log`로 사용됩니다. 로그의 밑·스케일은 JSON만으로 확정하지 않았습니다.

<a id="softplus"></a>
### SoftPlus

문턱 부근을 부드럽게 바꾸는 비선형 명암 변환 계열입니다. UI는 Lower/Higher/Sigmoid/Higher+Lower와 threshold, clarity, flatWidth 등을 제공합니다. 측면 Mask의 어두운 영역 처리 가지에 있지만 후속 Threshold가 이 노드가 아닌 앞선 Reverse 출력을 참조하므로 주 경로 사용 여부에 주의합니다.

<a id="makecolorimage"></a>
### MakeColorImage

입력 채널을 컬러 영상으로 구성합니다. UI 옵션은 Normal/AutoValue/ColorCal입니다. 측면 녹에서 RGB의 상대 응답을 만들고 표시 영상을 구성합니다. ColorCal의 정확한 보정식은 미확인입니다.

<a id="colorsplit"></a>
### ColorSplit

컬러 영상에서 Red/Green/Blue 채널을 선택합니다. 채널별 반응 차이는 표면 색상 변화 검출에 활용됩니다. HSV 등 다른 색공간 분리라고 추정하지 않습니다.

<a id="mergetransformed"></a>
### MergeTransformed

두 영상의 결합·보정 도구입니다. 옵션은 Add/Sub/Add(abs)/Sub(abs)입니다. 측면 JSON에서 기울기와 거칠기 영상을 Sub로 결합해 `보정 INH/INV`를 만듭니다. 이름만 보고 기하학적 정합 알고리즘이라고 해석하지 않습니다.

## 평활화·배경 보정

<a id="average"></a>
### Average

주변 픽셀 평균으로 노이즈를 줄이는 저역 통과 필터입니다. `I1/I2=Kernel X/Y`. 작은 결함·경계도 함께 약해질 수 있어 평균 후 대역 필터나 선 검출을 적용합니다.

<a id="gaussian"></a>
### Gaussian

주변에 가우시안 가중치를 주는 평활화입니다. UI `I1/I2=Step X/Y`. 넓게 평활화한 영상을 밝기 기준으로 사용하거나 주파수 마스크를 부드럽게 만듭니다. 이 값을 곧바로 물리 크기나 sigma로 환산하지 않습니다.

<a id="bilateral"></a>
### Bilateral

공간적 거리와 밝기 유사도를 함께 사용해 경계를 상대적으로 보존하며 노이즈를 줄입니다. `I1=d`, `P1=sigmaColor`, `P2=sigmaSpace`. 결함의 미세한 명암도 평활화될 수 있으므로 실제 이미지 확인이 필요합니다.

<a id="selfreference"></a>
### SelfReference

자기 영상으로부터 기준 성분을 만들거나 보정하는 도구로 추정합니다. UI는 Step X/Y를 제공합니다. 측면 스크래치 REF 경로에서 Bilateral 뒤, BPF 앞에 위치합니다. 기준 영상 생성식은 미확인입니다.

<a id="profilesmoothing"></a>
### ProfileSmoothing

행·열 프로파일을 Average/Max 방식으로 정리하는 계열입니다. Ignore Center Size, Reference Offset, Remove Mode가 있습니다. 측면 Mask에서 `종이검출활용이미지`를 만드는 데 사용되며 방향·제거식은 구현 확인이 필요합니다.

<a id="regionfilling"></a>
### RegionFilling

영상과 마스크를 함께 받아 지정 영역을 채우는 도구입니다. Mask Mode는 Normal/Reverse이고 외부 ROI 사용 옵션이 있습니다. 주파수 필터 전 마스크 경계·배경의 급격한 변화에 의한 가짜 응답을 줄이는 용도로 추정합니다. 채움 방식은 미확인입니다.

<a id="imagenormalize"></a>
### ImageNormalize

영상 값을 지정 범위로 정규화합니다. Manual/Auto, Range Min/Max 옵션이 있습니다. FFT 제거용 마스크를 평활화한 뒤 강도를 정리하는 단계에서 반복됩니다. 정규화 뒤 임계값은 원본 영상 단위와 다릅니다.

## 대역·주파수 필터

<a id="bpf"></a>
### BPF

Band-Pass Filter는 느린 배경 변화와 빠른 잡음 사이의 특정 크기 성분을 강조합니다. UI는 Basic/ABS/Positive/Negative, `P1=LS`, `P2=Low cut`, `P3=High cut`, Range min/max입니다. **0.35 같은 cut 값을 Hz·픽셀로 단정하지 않습니다.** 실제 대역 정의는 라이브러리 기준입니다.

<a id="bpf2"></a>
### BPF2

BPF와 같은 이름의 옵션을 가진 별도 도구입니다. 내경 Local의 거칠기·반사율 특징 추출에 사용됩니다. BPF와의 정확한 구현 차이는 미확인입니다.

<a id="singlebpf"></a>
### SingleBPF

Horizontal/Vertical 방향을 지정하는 대역 필터입니다. Basic/ABS/Positive/Negative와 LS·Low cut·High cut 옵션이 있습니다. 갭의 한 방향 성분이나 양·음 응답을 분리하는 데 쓰입니다.

<a id="fftimage"></a>
### FFTImage

공간 영상을 주파수 성분으로 분석하는 FFT 계열 도구입니다. Mode는 1D/2D이며 Scale 옵션이 있습니다. 반복 무늬는 주파수 공간에서 특정 위치·선으로 나타나므로 제거용 필터를 만들 수 있습니다. 반환 영상의 구체적 표현은 미확인입니다.

<a id="fftimage2"></a>
### FFTImage2

방향을 1D-H/1D-V/2D로 나눠 선택하는 FFT 도구입니다. 내경에서 REF·RGH·RGV·Theta·Phi의 주기적 패턴을 찾는 전처리에 반복 사용됩니다.

<a id="fftfilterline"></a>
### FFTFilterLine

UI Dir=Y/X, Size로 주파수 제거용 선·마스크를 구성하는 도구로 추정합니다. 선 또는 Blob 검출 후 Morphology·Gaussian과 함께 제거 마스크를 정리합니다. 단독 노드가 원본 패턴 제거까지 수행한다고 해석하지 않습니다.

<a id="removemaskfft"></a>
### RemoveMaskFFT

원본 영상과 주파수 필터 마스크를 받아 반복 패턴을 억제하는 계열입니다. FFT Mode=1D/2D, Filter Mode=Mask/Multi, `P1=Multi`. 특정 주파수를 줄이면 정상 적층 패턴뿐 아니라 같은 대역의 결함도 약해질 수 있습니다.

<a id="removemaskfft2"></a>
### RemoveMaskFFT2

FFT Mode=1D-H/1D-V/2D인 패턴 제거 도구입니다. 입력 마스크의 좌표·강도 정의와 내부 역변환 방식은 미확인입니다. 내경 Global이 Local에 전달할 패턴 제거 특징을 만드는 핵심 단계입니다.

## 임계값·미분·선 검출

<a id="threshold"></a>
### Threshold

명암 조건으로 후보를 분리합니다. Mode는 **0 Normal, 1 Otsu, 2 InRange**이고 부 옵션은 Manual/Memory입니다. `P1` UI 이름은 Threshold Max입니다. **Mode 2를 반전 이진화라고 해석하면 안 됩니다.** `밝음/어두움`은 JSON 작성자가 붙인 결과명이며 실제 범위·메모리 옵션은 원본 전체 설정을 확인해야 합니다.

<a id="edgethreshold2"></a>
### EdgeThreshold2

국소 경계·명암 차이에 기반한 문턱 처리 계열로 추정합니다. Kernel Shape, `I1=Kernel`, `I2=Offset`, `P1=Threshold`가 있습니다. 일반 Threshold와 별도 도구이며 정확한 비교식은 미확인입니다.

<a id="profilethreshold"></a>
### ProfileThreshold

프로파일 통계 Average/Max에 Threshold Ratio를 적용하는 도구입니다. Ignore Center Size와 Remove Mode가 있습니다. FFT 영상의 두드러진 반복 성분을 찾아 제거 마스크를 구성하는 데 사용됩니다.

<a id="blobthreshold"></a>
### BlobThreshold

Blob별 임계값 또는 전체 Blob 정보를 기준으로 문턱 처리를 적용합니다. 내경 Mask의 상관 응답에서 반복 영역을 고르는 단계에 쓰입니다. 어떤 통계량을 쓰는지는 구현 확인이 필요합니다.

<a id="differential"></a>
### Differential

방향별 밝기 변화율을 계산해 경계를 강조합니다. X_L2R/Y_T2B/X_R2LR/Y_B2T/XY_LT2RB/XY_RB2LT/All, Normal/Abs 옵션과 Step, Base Offset이 있습니다. 평탄한 배경은 줄이고 급격한 변화는 강조하지만 잡음도 커질 수 있습니다.

<a id="sobel"></a>
### Sobel

주변 픽셀의 가중 차분으로 기울기를 구합니다. X/Y/AbsX/AbsY/XY/AbsXY, Threshold Use/UnUse, Kernel·Threshold 옵션이 있습니다. 갭 검사에서 외곽선 응답을 만드는 데 사용됩니다.

<a id="linesearching"></a>
### LineSearching

지정 중심 각도와 ±범위에서 선형 특징을 탐색하는 도구입니다. `I1=Kernel`, `P1=Theta Resolution`, `P2=중심 각도`, `P3=±범위 각도`, ScaleMin UI=Resize입니다. Hough 등 특정 구현이라고 단정하지 않습니다. 결과명의 방향보다 실제 중심 각도 값을 우선합니다.

<a id="anglethresholdfilter"></a>
### AngleThresholdFilter

각도 관련 조건으로 선·Blob을 선별하는 도구로 추정합니다. UI에는 Morp Mode, Output Mode, Kernel이 있습니다. JSON의 `수직 노이즈/수평 노이즈`는 의도 설명이며 실제 조건이 다를 수 있습니다. 같은 설정의 두 노드를 서로 다른 방향 필터로 단정하지 않습니다.

<a id="lineextraction_basic_filtering"></a>
### LineExtraction_Basic_Filtering

Blob 후보와 특징 영상을 받아 선형 결함을 정리하는 도구로 추정합니다. UI는 선찾기 Kernel, Blob Margin을 제공합니다. 내경 SC에서 반짝임·거칠기의 선형 후보 선별에 사용됩니다.

## 형태학·검사 영역

<a id="morphology"></a>
### Morphology

마스크를 구조 요소로 수축(Erode)·팽창(Dilate)합니다. Open은 수축 후 팽창으로 작은 돌출·잡음을 줄이고, Close는 팽창 후 수축으로 작은 틈을 메웁니다. UI에는 Gradient, Tophat, Blackhat, In Edge, Out Edge도 있습니다. Kernel Shape=Rect/Cross/Ellipse, `I1/I2=Kernel X/Y`.

UI의 Gradient 설명은 `Close-Open`으로 표시되어 있어 일반적인 `Dilate-Erode` 정의와 혼동하지 않아야 합니다. 실제 크기 효과는 해상도와 앞선 Resize/Crop에 따라 달라집니다.

<a id="directionalmorphology"></a>
### DirectionalMorphology

Left/Top/Right/Bottom/TB/LR/All 방향의 형태학 연산입니다. Mode=Erode/Dilate/Open/Close, `I1=Kernel`. 측면 갭·바니시·Edge찍힘에서 특정 경계 방향의 마스크를 만들거나 정리합니다.

<a id="makemask"></a>
### MakeMask

지정 위치·크기의 마스크를 생성합니다. `I1=X`, `I2=Y`, `P1=Width`, `P2=Height`. 고정 검사 영역·제외 영역에 쓰이며 카메라 위치가 달라지면 영역이 어긋날 수 있습니다.

<a id="makecentermask"></a>
### MakeCenterMask

Center/Outline/Manual 모드로 중심 또는 외곽 관련 마스크를 만듭니다. `I1/I2=Size X/Y`. 여러 Local JSON은 **Outline 모드**를 사용하므로 이름만 보고 중심 사각형을 생성한다고 단정하지 않습니다.

<a id="makeedgemask2"></a>
### MakeEdgeMask2

경계를 스캔해 마스크를 만드는 전용 도구입니다. Max Point/First Point, Normal/Calc 옵션과 Scan Width, Top/Bottom Point 등을 제공합니다. 측면 Mask의 최종 저장 마스크를 만듭니다. 구체적 스캔 경로는 구현 미확인입니다.

<a id="makepatternmask"></a>
### MakePatternMask

검출된 반복 요소에서 패턴 기준 마스크를 만드는 도구로 추정합니다. 내경 Mask의 종이·노치 후보 뒤에 있으며 Correlation1D의 기준 입력으로 사용됩니다.

<a id="makeprofilelinesumimage"></a>
### MakeProfileLineSumImage

X Sum/Y Sum 방향으로 값을 누적하는 프로파일 영상 도구입니다. 반복 구멍·배경의 위치를 한 방향 통계로 강조하는 데 활용됩니다. 실제 합산 대상과 출력 배치는 구현 확인이 필요합니다.

## Blob·윤곽·ROI 판별

<a id="blobcontourcriteria"></a>
### BlobContourCriteria

연결 영역의 윤곽을 찾고 면적·폭·길이·비율 등의 조건으로 선별하는 계열입니다. Blob Mode=And/Or, Blob Return=Label Image(원문 `Lable`)/Blob Group(원문 `Grop`), Rect Offset 옵션이 있습니다. 조건 콤보의 숫자를 임의로 `이상/이하`로 해석하지 않았습니다.

<a id="blobcontourcriteria2"></a>
### BlobContourCriteria2

BlobContourCriteria와 유사한 UI를 갖는 별도 구현입니다. 작은 노이즈·선형 후보를 정리하는 Local 단계에 자주 사용됩니다. 버전별 차이·윤곽 추출 방식은 미확인입니다.

<a id="contourcriteria"></a>
### ContourCriteria

윤곽 조건 기반의 선별 도구입니다. Blob Mode, Blob Return, Rect Offset UI가 있습니다. 갭의 선 응답을 정리하는 데 사용되며 BlobContourCriteria와 동일한 구현이라고 단정하지 않습니다.

<a id="bloblabelcriteria"></a>
### BlobLabelCriteria

연결 성분 라벨 기반으로 영역을 선별하는 계열입니다. Blob Mode=And/Or, Rect Offset 옵션이 있습니다. 내경 Global의 최종 후보·FFT 마스크 생성에 사용됩니다.

<a id="overlapblobcriteria"></a>
### OverlapBlobCriteria

두 영상의 Blob·마스크 간 겹침을 조건으로 후보를 선별하는 도구입니다. Blob Mode=And/Or. 갭의 검사 영역 안 후보를 골라내거나 경계 잡음과 겹친 후보를 분리하는 데 사용됩니다. 겹침 비율·보존 방향은 설정 전체와 구현을 확인해야 합니다.

<a id="overlapblobcriteria2"></a>
### OverlapBlobCriteria2

겹침 선별의 별도 구현입니다. 측면의 Top/Center/Bottom 영역 제외, 귀 갭의 검사 마스크 선정 등에 사용됩니다. 이름만으로 Criteria와의 차이를 확정할 수 없습니다.

<a id="blobarithmetic"></a>
### BlobArithmetic

특징 영상과 Blob을 함께 받아 Blob 단위의 특성·조건을 처리하는 도구로 추정합니다. `P3` UI는 기준값입니다. 내경 Dent/Epoxy에서 3D 계열 영상과 결함 후보를 결합합니다. 구체적 높이·부피 계산이라고 단정하지 않습니다.

<a id="blobdimension"></a>
### BlobDimension

Blob의 치수·단면을 다루는 도구입니다. Search X/Search Y, Manual/Auto, Split, Auto Offset UI가 있습니다. 내경 Mask에서 종이·노치 위치로 에폭시 관련 후보를 만드는 경로에 있습니다. 측정값을 mm로 보려면 별도 보정 정보가 필요합니다.

<a id="blobmaskrectifier"></a>
### BlobMaskRectifier

Blob 기반 마스크의 형태·좌표를 정리하는 도구로 추정합니다. 내경 Mask의 최종 종이Mask·노치Mask를 만드는 데 사용됩니다. 정류·보정 수식은 미확인입니다.

<a id="blobroipacking"></a>
### BlobROIPacking

여러 Blob ROI를 Packing/Unpacking하는 도구입니다. 내경 갭의 추가 외부 갭 경로에서 관심 영역을 모아 처리한 뒤 복원하는 용도로 추정합니다. ROI 메타데이터와 원래 좌표 보존이 중요합니다.

<a id="blobroifindedge"></a>
### BlobROIFindEdge

Blob ROI를 기준으로 경계 위치를 찾는 도구입니다. 내경 갭에서 미분 영상과 `선 위치` 결과를 함께 사용합니다. 탐색 방향·서브픽셀 정밀도는 미확인입니다.

<a id="blobroifindedgethreshold"></a>
### BlobROIFindEdgeThreshold

ROI 경계 탐색 후 거리·응답을 Threshold/Value 모드로 다루는 도구입니다. `I1=Resize`, `P1=Threshold(Distance)`. 내경 갭의 `외부갭2`는 Value 모드로 저장되어 Local에서 다시 Threshold 처리됩니다.

## 좌표 변환·이미지 전달

<a id="sigmacirclefitting"></a>
### SigmaCircleFitting

윤곽으로 원을 맞추고 이상점 영향을 줄이는 원 피팅 계열입니다. Circle Draw=Fill/Line, Contour Mode=Max/All, Radius Min/Max, sigmaMultiplier가 있습니다. 내경 원주 펼침의 기하 기준을 만드는 것으로 추정합니다.

<a id="unwrapcircletorect"></a>
### UnwrapCircleToRect

원주·환형 영상을 각도와 반지름 방향의 직사각 영상으로 펼칩니다. Radius Mode, Width Mode, Offset, Radius, Polar Width를 설정합니다. 내경의 반복 적층 패턴을 직선 방향으로 처리할 수 있지만 이음매와 보간 오차에 주의해야 합니다.

<a id="unwraprecttocircle"></a>
### UnwrapRectToCircle

펼친 직사각 영상을 원주 좌표로 되돌리는 계열입니다. Radius/Offset의 Auto/Manual 옵션이 있습니다. 내경 Mask의 중간 원형 마스크 생성에 사용되며 이후 최종 출력이 다시 펼침 좌표일 수 있으므로 결과명을 기준으로 좌표계를 단정하지 않습니다.

<a id="maske2rectresizer3"></a>
### Maske2RectResizer3

마스크를 기준으로 UnWrap/ReWrap하는 전용 변환입니다. UI는 Gaussian, Value를 제공합니다. 측면에서 형상 변화가 있는 영역을 Rect 좌표로 펴고 처리 후 되돌리는 용도로 추정합니다. 내경의 원주 펼침과 동일한 수식이라고 볼 근거는 없습니다.

<a id="makecropimage"></a>
### MakeCropImage

Auto/Manual 모드로 관심 영역을 잘라내는 도구입니다. 여러 입력·ROI 설정이 있으며 후속 JSON이 여러 영상 슬롯을 참조하므로 단일 출력 노드라고 가정하면 안 됩니다. 상세표의 기본 슬라이더만으로 Crop 범위 전체를 알 수는 없습니다.

<a id="cropimageoverlay"></a>
### CropImageOverlay

잘라 처리한 영상과 기준 영상을 합쳐 좌표를 복원·배치하는 도구로 추정합니다. 측면 Global에서 Local에 넘길 특징 영상을 구성합니다. 표시용 컬러 덧그리기인 MaskColorOverlay와 구분합니다.

<a id="makeresizeimage"></a>
### MakeResizeImage

Auto/Manual, Resize Width/Height, Result Scale로 영상 크기를 바꾸는 도구입니다. ROI·마스크 영상과의 크기 일치가 중요합니다.

<a id="imageresize"></a>
### ImageResize

LT/RT/LB/RB/Center 기준점과 Crop/Return/Ratio Crop 모드를 갖는 크기·영역 조정 도구입니다. 측면 녹에서는 Red·Blue 입력의 Resize px가 서로 다릅니다. 일반적인 동일 배율 리사이즈라고 단정하지 않습니다.

<a id="imageshift"></a>
### ImageShift

ShiftX/ShiftY만큼 영상 위치를 이동합니다. 반복 마스크 경계 정렬이나 제외 범위 보정에 사용됩니다. 이동 방향 부호와 외부 채움 방식은 런타임 확인이 필요합니다.

<a id="copyfilter"></a>
### CopyFilter

원본 영상과 기하 기준을 받아 복사·전달하는 도구입니다. 내경 Mask에서 여러 채널을 동일한 원 피팅 기준에 맞춰 펼치기 전에 사용됩니다. 픽셀 복사 이외의 메타데이터 전달 여부는 미확인입니다.

<a id="outputimage"></a>
### OutputImage

선택 영상을 결과명으로 저장/노출하기 위한 전달 노드입니다. 새로운 검출 기법이 아니라 전처리와 다음 단계 사이의 입력 계약을 표현합니다.

<a id="clearfilter"></a>
### ClearFilter

중간 결과를 정리·초기화하는 이름의 전용 도구입니다. 픽셀, Blob, ROI 중 무엇을 지우는지 확인되지 않았습니다. 이름만 보고 잡음 제거 필터 또는 모든 픽셀을 0으로 만드는 노드라고 단정하지 않습니다.

## 패턴 상관·기울기·결과 분석

<a id="correlation1d"></a>
### Correlation1D

1차원 패턴과의 상관으로 반복 위치의 유사도를 평가하는 계열입니다. 내경 Mask에서 MakePatternMask와 함께 종이·노치 반복 배열을 찾는 데 사용됩니다. 정규화 상관 여부는 미확인입니다.

<a id="slopetothetaphi"></a>
### SlopeToThetaPhi

두 기울기 입력에서 Theta/Phi 성분을 구성하는 전용 변환입니다. Clock/ClockWise와 Initial Phase 옵션이 있습니다. 내경 Mask의 2DTHETA/2DPHI 경로를 만듭니다. 각도 정의·단위와 출력 개수는 구현 확인이 필요합니다.

<a id="thetareference"></a>
### ThetaReference

원주 위치에 따른 기울기·각도 기준을 처리하는 전용 도구입니다. Clock/ClockWise, Pi/TwoPi, StartPos가 있습니다. 내경 PolarTheta 기울기 보정 경로에 사용됩니다.

<a id="make3dimage"></a>
### Make3DImage

두 기울기 성분에서 3D 계열 특징 영상을 만드는 도구입니다. Basic/ABS/Positive/Negative, Normal/InvertH/InvertV/InvertAll과 LS·Low cut·High cut 옵션이 있습니다. 보정·캘리브레이션 없이 결과를 실제 깊이(mm)라고 부를 수 없습니다.

<a id="euclideandistance"></a>
### EuclideanDistance

기울기 두 성분을 함께 받는 거리·크기 계열 도구입니다. 일반적인 유클리드 크기는 `sqrt(x²+y²)`이나 해당 DLL이 이 수식을 그대로 사용하는지는 미확인입니다. 측면 찍힘에서는 INH/INV의 복합 강도 경로로 추정합니다.

<a id="poscocriteria"></a>
### PoscoCriteria

전용 Blob 판별 도구입니다. Blob Mode=And/Or, Avg Value Use=Src 0/Src 1, Src 0/1 Avg Multi UI가 있습니다. 녹·바니시·Edge찍힘에서 후보와 특징 강도를 함께 검토하는 용도로 추정합니다. 특정 회사 규격·합격 기준을 뜻한다고 단정하지 않습니다.

<a id="poscofiltering"></a>
### PoscoFiltering

전용 후보 필터링입니다. Blob Mode=And/Or, ROI Offset UI가 있습니다. 측면 찍힘에서 후보와 BPF 특징들을 함께 받습니다. PoscoCriteria와의 수식 차이·불량 기준은 미확인입니다.

<a id="histogramarithmetic"></a>
### HistogramArithmetic

분포 통계를 활용한 조건 연산입니다. Mode=Under/Over, Output Value, Value Threshold(%) UI가 있습니다. 측면 바니시에서 PoscoCriteria 결과와 3D 계열 특징을 결합합니다. 퍼센트 값은 물리적 도막 두께가 아닙니다.

<a id="imageanalysis"></a>
### ImageAnalysis

결함 후보와 여러 특징 영상의 분포·최대값·평균 기반 분석을 수행하는 결과 단계로 추정합니다. UI에는 Process Show Image=Src 0/1/2, Histogram Ratio, Max Ratio, Src 0/1/2 Avg Multi가 있습니다. 네 번째 이미지 참조도 기록하므로 앞선 세 개만으로 연결을 판단하면 안 됩니다.

모든 실제 Local 파일에 `SaveUse=true`인 ImageAnalysis가 있습니다. 반환 ROI·표시 영상 생성과 정확한 수치 산식은 DLL 동작 확인이 필요합니다. 앱의 최종 OK/NG 판정은 위의 실행 코드 설명과 별개입니다.

<a id="maskcoloroverlay"></a>
### MaskColorOverlay

원본 위에 마스크를 컬러로 표시하는 시각화 도구입니다. Draw Mode=Fill/Overlay, `P1/P2/P3=Red/Green/Blue`. 보통 확인용 마지막 노드이며 `SaveUse=false`인 오버레이가 최종 판정 데이터로 반환된다고 단정하지 않습니다.
